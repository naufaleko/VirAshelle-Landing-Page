# Anti-Slop Report #002: Admin Dashboard (antislop-ui)

**Tanggal**: 2026-09-20
**Skill**: `antislop` (core) + `antislop-ui`
**Mode**: 1 (DURING): temuan langsung diperbaiki, lalu Delivery Gate dijalankan.
**Lingkup**: `src/admin/**` (Overview, Laporan Keuangan, Invoice, Proyek, Detail Proyek, CMS, Login, shell), `src/index.css` (token + focus ring).
**Di luar lingkup**: landing page (`src/components`), lembar invoice cetak (`#invoice-card`, dokumen putih), copywriting campur bahasa di halaman Detail Proyek.

## Design Read

> Reading this as: internal admin dashboard untuk studio kreatif kecil (VirAshelle), diarahkan oleh identitas website publiknya: permukaan hitam, satu aksen hijau `#4BD200`, Arsenal untuk UI, Inter untuk display. Dial **ENERGY 2 / RHYTHM 2 / MOTION 2**.

Tidak ada `DESIGN.md`. Arah diambil dari kode landing page (palet, font, tema gelap). Disarankan owner menulis `DESIGN.md` sendiri agar arah ini tercatat resmi, bukan disimpulkan dari kode.

## Keputusan dan alasannya (R-31)

| Keputusan | Alasan satu baris |
| :--- | :--- |
| Tema gelap tetap | Studio kreatif; konsisten dengan situs publik yang juga hitam-hijau (R-21). |
| Palet: hitam/zinc (netral) + 1 aksen `#4BD200`; semantik: merah `#ff3344` = keluar/bahaya, amber = perlu perhatian | Batas 2-3 inti + 1 aksen (R-29); biru, cyan, emerald, ungu, pink dibuang. |
| Warna status proyek = ramp hijau (`STATUS_COLORS` di `projectStatus.ts`) | Status adalah progresi; satu warna berarti hal yang sama di badge, daftar tahap, dan detail. |
| Card solid `#111118`, tanpa blur, tanpa shadow | Halaman hitam datar: tidak ada apa pun di balik card untuk di-blur, dan bayangan di atas hitam tidak mengomunikasikan apa-apa (R-10, R-12). |
| Glass hanya di header sticky | Konten benar-benar scroll di bawahnya; itu satu-satunya permukaan yang layak blur (R-10). |
| Shadow hanya di overlay (modal, dropdown, kartu hover chart) | Elevasi hanya untuk yang benar-benar melayang di atas halaman (R-12). |
| Glow hanya di garis chart kas (filter SVG) + node saat hover | Chart adalah fokus visual halaman keuangan; satu aksen glow, bukan di semua elemen (R-13). |
| Hairline hijau statis di satu card fokus per halaman (Ringkasan: saldo kas; Keuangan: saldo kas; Login: card; modal proyek) | Motif identitas: menandai elemen yang menjadi alasan halaman itu ada. Hairline hover-only di card lain dibuang. |
| Label sentence case, tanpa uppercase tracking lebar | Arsenal sudah punya karakter; uppercase 10px tracking 0.25em adalah default AI, bukan tipografi (R-06). |
| Angka uang dan ID selalu `font-mono`, label selalu Arsenal | Suara tipografi yang konsisten; angka mudah dipindai. |
| Ikon Lucide dipertahankan | Semua ikon fungsional (nav, aksi, jenis transaksi), bukan dekorasi fitur; stroke 1.5px cocok dengan bobot ringan Arsenal (R-04). Sparkles, bintang, AlertTriangle-untuk-status diganti glyph yang menamai aksinya. |
| Dot status hanya untuk state nyata: realtime channel (SUBSCRIBED), invoice aktif di editor, status proyek | Dot tanpa state dibuang (header, logo, heading chart, label revenue); tidak ada pulse/ping tanpa henti (R-19, R-31). |
| Motion: transisi modal masuk/keluar + garis chart digambar sekali saat mount; fade-in per card dihapus | Dial MOTION 2: transisi dengan tujuan, tanpa loop dan tanpa koreografi masuk untuk tool yang dibuka puluhan kali sehari (R-19). |
| Overview disusun ulang: saldo kas (fokal) / kas masuk / proyek aktif / lewat tenggat; completion rate dibuang; donut diganti daftar tahap | Layar menjawab "kas aman?" dan "proyek mana yang perlu perhatian?"; `overdue` sudah dihitung tapi tidak pernah ditampilkan, sementara completion rate tak punya keputusan di baliknya (C-3, R-20). |
| Breakdown pengeluaran = daftar bar berperingkat, bukan bar spektrum 10 warna | Panjang bar membedakan kategori; hue tidak perlu; jawaban "ke mana kas keluar" terbaca dalam satu pandangan. |
| Token `--color-dim: #8b8b95` menggantikan `zinc-500/600` untuk teks paling redup | 5,6:1 di card, 6,0:1 di hitam; `zinc-500` hanya 3,9:1 di card (R-25). |
| Tombol merah pakai teks hitam | Putih di `#ff3344` = 3,6:1 (gagal); hitam = 5,8:1, konsisten dengan tombol hijau (R-25). |
| Budget proyek ditampilkan `Rp` | Invoice dan buku kas seluruhnya rupiah; `$` adalah sisa template. **Asumsi**: budget memang dicatat dalam rupiah. |

## Temuan yang diperbaiki

### HIGH (Hard Gate)
1. **R-25** `text-zinc-500` (3,9:1) dan `text-zinc-600` (2,4:1) di 114 tempat: label, timestamp, placeholder. → token `text-dim`.
2. **R-25** Teks putih di tombol merah `#ff3344`/`red-500` (3,6-3,8:1): toggle Keluar, submit expense, "Ya, Hapus". → teks hitam.
3. **R-27** Overview dan Projects tidak punya error state (hook menelan error); Finance tidak punya loading state dan tidak menampilkan `error` dari `useFinance`. → `error` diekspos dari `useProjects`, `useProjectStats`, `useProjectDetail`; panel error + aksi (muat ulang / coba lagi) di empat halaman; loading state bernama.
4. **R-27** Empty state "Tidak ada proyek", "Belum ada transaksi" tanpa sebab dan aksi. → membedakan "belum ada" vs "filter tidak cocok", masing-masing dengan langkah berikutnya.
5. **R-32** Modal tanpa Escape: bukti transaksi, konfirmasi hapus, TransactionModal, JourneyMap fase, BrandedDropdown, sidebar mobile. → hook `useEscapeKey`.
6. **R-32** `ProjectCard` adalah `div onClick` tanpa `tabIndex`/keyboard. → `role=button`, Enter/Space.
7. **R-32** Node bulan di chart hanya bisa hover. → `tabIndex`, `onFocus`, `aria-label` berisi nilai.
8. **R-32** Tidak ada focus ring global; tombol tanpa indikator fokus. → `:focus-visible { outline: 2px solid brand }`.
9. **R-32** Tombol ikon tanpa nama: toggle menu mobile, collapse sidebar (`<`/`>` teks), tutup modal `✕`, hapus/lihat bukti. → `aria-label` + ikon.
10. **R-03** Chart di 390px gepeng jadi 77px dengan teks 3px; label tab mode patah baris. → SVG `min-w-[640px]` scroll horizontal di bawah `sm`, `whitespace-nowrap` di tab, ukuran teks sumbu dinaikkan, gutter kiri 80.
11. **R-36/R-38** "Live Ledger Telemetry" + dot berdenyut dan copy "real-time" tanpa bukti koneksi. → indikator "Realtime aktif/terputus" diikat ke status channel Supabase (`live` dari `useFinance`).
12. **R-38** Caption "Roadmap delivery tepat waktu" di angka yang sebenarnya hanya rasio selesai/total. → metrik dibuang.
